# Дополнительные корневые сертификаты

Сюда кладут корневые сертификаты, которых нет в системном хранилище контейнера.
Практический случай — корень **Минцифры** («Russian Trusted Root CA»): им подписаны
сертификаты сайтов Т-Банка, и без него исходящий запрос к `securepay.tbank.ru`
завершается ошибкой проверки сертификата, а покупатель видит «Т-Банк временно не
ответил».

- файлы `*.pem` и `*.crt` из этой папки подхватываются автоматически при старте;
- их же копирует в системное хранилище образ (`Dockerfile`);
- альтернатива без правки репозитория: переменная `EXTRA_CA_PEM` (содержимое PEM
  целиком) или `EXTRA_CA_BUNDLE` (путь к файлу на хостинге).

Сертификат сайта g-partner.store сюда класть не нужно: он вместе с приватным ключом
устанавливается в настройках HTTPS у хостинга, а не в приложении.
