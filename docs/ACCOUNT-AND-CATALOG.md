# Фото, сохранение входа и удаление товаров

## Фотографии

В каталоге и карточке товара убраны дополнительные отступы вокруг изображения. Квадратная область использует всё доступное место. Сохраняется `object-fit: contain`: колёса, зеркала и прочие детали не обрезаются ради увеличения. Миниатюры галереи тоже квадратные, без белых полос. Исходные фото и данные товаров не меняются.

## Сохранение входа

Формы регистрации, общего входа и `/admin` имеют отметку **«Оставаться в системе на этом устройстве»**. Она включена по умолчанию по запросу владельца, но её нужно снять на чужом устройстве.

- Покупатель: до 60 дней **от последнего захода**, не более 30 дней бездействия. Каждое открытие витрины отодвигает и серверный срок, и срок самой cookie, поэтому постоянный покупатель не выпадает из аккаунта по календарю. Срок без захода остаётся прежним.
- Администратор: до 14 дней, не более 7 дней бездействия.
- Без отметки: cookie только для сеанса браузера, серверный срок до 8 часов. Для администратора также действует часовой тайм-аут бездействия.
- «Выйти» удаляет серверную сессию; подстановка старого cookie не восстанавливает вход.
- Смена пароля владельца по-прежнему отзывает его сессии.
- Личный кабинет заново проверяет серверную сессию владельца при открытии, поэтому после обновления страницы показывает доступ в CRM, а не повторную форму входа.
- Тому, кто уже входил, кабинет вместо формы входа показывает «восстанавливаем сессию», пока сервер отвечает. Признак прошлого входа (только `1`, без имени и контакта) лежит в `localStorage` под ключом `gpartner.signed-in.v1` и снимается, когда сервер отвечает, что посетитель вышел. Обрыв связи признак не снимает: иначе одна неудачная загрузка выглядела бы как выход из аккаунта.

Пароли и токены не записываются JavaScript-кодом в localStorage. Cookie остаются HttpOnly, SameSite=Strict, Secure при HTTPS. Сервер проверяет CSRF для изменений. Выбранные сроки — продуктовый компромисс для личного устройства, не универсальная рекомендация по безопасности; длительный вход повышает риск на потерянном или общем устройстве. Основа механизмов защиты: [OWASP Session Management](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html).

Ранее открытые короткие сессии не продлеваются автоматически. Чтобы включить длительное сохранение, после обновления один раз войдите с отметкой. В обычном браузере и Telegram могут быть разные хранилища cookie — вход сохраняется отдельно в каждом. Приватный режим и очистка данных браузера могут удалить сохранённый вход раньше срока.

## Удаление

Кнопка **«Удалить товар»** доступна прямо в списке CRM и в шапке редактора. Подтверждение показывает название выбранного товара. Отмена не отправляет запрос. Ошибка удаления оставляет карточку на месте и выводит сообщение. Удаление другой карточки не сбрасывает несохранённые изменения открытого товара.

Удаление окончательное для панели; вернуть товар можно из резервной копии. Фотографии сервер сохраняет, поскольку на них могут ссылаться ранее отправленные заявки. Для временного скрытия товара используйте «Сохранить черновик».

## Проверки

```powershell
python -m unittest discover -s tests
cd apps/mini-app
npm test
npm run build
npm run dev -- --port 5192 --strictPort
# В другом терминале из apps/mini-app:
node src/storefront/photos-check.mjs
node src/admin/browser-check.mjs
```

Браузерная проверка CRM использует только локальную страницу с замоканными API. Рабочие товары не удаляются. Снимки сохраняются в `apps/mini-app/test-results/admin-session-delete/`.
