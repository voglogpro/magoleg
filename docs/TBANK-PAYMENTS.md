# Подключение оплаты Т-Банка

Статус на 14.09.2026: серверная интеграция интернет-эквайринга для СБП подготовлена. «Долями» временно скрыто на всём сайте; код и лимит строго менее 30 000 ₽ сохранены для будущего включения. Рассрочка и кредит показываются только после перевода соответствующего способа в статус «Доступно».

## Что получить после одобрения

- `TerminalKey` интернет-эквайринга;
- секретный пароль терминала для формирования `Token`;
- параметры онлайн-кассы и ставку НДС для товаров;
- доступ и документацию именно для «Долями», POS-кредита и рассрочки;
- подтверждённые `NotificationURL`, `SuccessURL` и `FailURL` для домена `g-partner.ru`.

Секретный пароль нельзя добавлять в GitHub или передавать во фронтенд. Он хранится только в переменной окружения сервера.

## Требования к вызову `/v2/Init`

- `Amount` и суммы позиций `Receipt.Items` передаются в копейках и должны совпадать;
- `OrderId` уникален для каждой попытки оплаты;
- `Token` формируется на сервере из корневых полей запроса и пароля терминала;
- `Description` не длиннее 140 символов для универсальной совместимости;
- данные чека передаются в `Receipt`, если подключена онлайн-касса;
- клиент получает только `PaymentURL` и переходит на защищённую форму Т-Банка;
- итоговый статус заказа меняется только после проверенного сервером уведомления.

## Переменные BotHost

- `TBANK_TERMINAL_KEY` — TerminalKey терминала;
- `TBANK_PASSWORD` — секретный пароль терминала;
- `PUBLIC_ORIGIN=https://g-partner.ru` — адрес для уведомлений и возврата покупателя;
- `TBANK_TAXATION` и `TBANK_ITEM_TAX` — задаются только по параметрам подключённой онлайн-кассы.

После добавления ключей сервер создаёт заказ со статусом `awaiting_payment`, вызывает `/v2/Init` и возвращает ссылку банка. Статус `paid` устанавливается только по уведомлению `CONFIRMED` с корректным Token, TerminalKey, PaymentId и суммой. Доставка в Amount и Receipt не передаётся.

Для писем добавьте `SMTP_HOST`, `SMTP_PORT`, `SMTP_USERNAME`, `SMTP_PASSWORD`, `SMTP_FROM`. Для SMS можно указать `SMS_WEBHOOK_URL`.

## Перед включением в боевом режиме

Проведите на тестовом терминале успешную оплату, отказ, повторное уведомление и возврат. В настройках терминала оставьте доступным только нужный сценарий СБП, чтобы банковская форма не предлагала оплату картой.

Официальная документация: <https://developer.tbank.ru/eacq/api/init>
