# Утверждённое направление G-Partner

Пользователь одобрил все три референса для внедрения: мягкие графитовые поверхности, строгое оформление в духе iPhone, тонкие границы, белая типографика, оранжевые округлые кнопки. Реализация адаптируется под ширину экрана, без декоративного корпуса телефона вокруг рабочего интерфейса.

- `cart-original.jpg` — исходное изображение пользователя, сохранено без изменений.
- `home-v1.png` — сгенерированный встроенным imagegen референс всей главной.
- `catalog-v1.png` — сгенерированный встроенным imagegen референс каталога.
- `prompts.md` — запросы генерации. Для главной дополнительно передана существующая фотография `mobile-hero-v1.jpg`, для каталога — четыре фотографии из `public/products/kugoo-2026/` в порядке M2+, F3 PLUS, WISH 01 SE, V3 PRO MAX.

Изображения являются визуальными референсами. Силуэты, отдельные надписи и логотипы, придуманные генератором, не заменяют реальные фотографии, фирменный знак или сведения магазина. Цены и наличие рабочего сайта берутся из API. Бесплатная доставка, срок рассрочки и фиктивный адрес СДЭК с исходной картинки не становятся обещаниями магазина.

## Реализация

Общая тема находится в `apps/mini-app/src/storefront/reference-theme.css`, корзина — в `Cart.tsx` и `cart.css`. Сохранены Inter и Montserrat; подключено начертание Montserrat 600. Категории главной используют опубликованные фотографии. Карточки каталога сохраняют сравнение, избранное, наличие, характеристики и покупку. Корзина использует рабочие обработчики количества, удаления, выбора города и заявки; доступность рассрочки и сроки доставки берутся из настроек.

При закрытом приёме заявок основная кнопка ведёт к контактам. При включённой рассрочке — к условиям оплаты. При открытом приёме заявок — к форме; неопубликованные и отсутствующие товары блокируют отправку.

## Проверка

Сборка `npm run build`, существующие 85 модульных тестов и четыре новых проверки корзины. Браузерная регрессия `src/storefront/browser-check.mjs` проверяет 344 сценария на пяти ширинах. `src/storefront/reference-check.mjs` использует публичные данные магазина, блокирует API-записи и сохраняет главную, каталог и корзину на 320, 390, 768 и 1440 px в `test-results/reference-design/`.
