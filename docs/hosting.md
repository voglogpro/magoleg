# Схема размещения

Статус документа: план для следующих этапов. В текущей UI-only версии серверы и Telegram-бот не разворачиваются.

## BotHost

На BotHost будет размещаться только процесс Telegram-бота: команды, кнопка запуска Mini App и перенаправление пользователя в веб-интерфейс. Токен бота должен храниться в секретах хостинга, а не в Git или клиентском bundle.

Точки входа находятся в корне репозитория: `main.js` — основная для запуска, `index.js` — совместимая альтернативная точка и реализация бота. Команда запуска: `npm start` или `node main.js`.

Обязательные секреты BotHost:

- `BOT_TOKEN` — токен Telegram-бота;
- `MINI_APP_URL` — публичный HTTPS-адрес собранного Mini App.

## Mini App

Статическая production-сборка `apps/mini-app/dist` должна размещаться на HTTPS-хостинге. Её публичный URL позже указывается в настройках Telegram-бота.

## Будущий backend

API, база данных, CRM, расчёт доставки и интеграция рассрочки не должны выполняться в браузере или в статическом bundle. Для них потребуется отдельный российский серверный контур с HTTPS, секретами и журналированием. Клиент будет обращаться к нему через `VITE_API_BASE_URL`.

До подключения этого контура все соответствующие элементы интерфейса остаются явно помеченными как mock/заглушки.
